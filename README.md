# DONIA SMART CLASSE
### توزيع الأقسام الذكي للمؤسسات التعليمية الجزائرية

تطبيق ويب يبني تلقائيًا أفواج السنة الدراسية القادمة لمتوسطتك، انطلاقًا من نتائج العام الحالي، حسب القواعد الرسمية للانتقال والإعادة — مع تعديل يدوي كامل وتصدير جاهز لصيغة Excel.

تطوير **[DONIA LABS TECH](https://donialabstech.online)** — حلول رقمية مبتكرة لأجلكم

## ✨ المزايا

- توزيع تلقائي متوازن (في العدد والجنس) للسنة الأولى من الوافدين الجدد ومعيدي الأولى.
- خيار "الحفاظ على الأفواج الحالية" أو "إعادة توزيع متوازن بالكامل" لكل من السنوات 2 و3 و4.
- استيراد مباشر لملفات منظومة وزارة التربية (xls/xlsx) — بلا أي تنسيق خاص أو إعداد إضافي.
- استخراج قوائم المعيدين والموجَّهين لمراكز التكوين المهني تلقائيًا.
- تعديل يدوي فوري: تغيير قسم أي تلميذ، تصحيح الجنس، حذف تلميذ — كل ذلك بدون أي زر "حفظ" أو "تنفيذ".
- ترويسة رسمية (الجمهورية/الوزارة/المديرية/المؤسسة) قابلة للتعديل بالكامل، تظهر في كل ملفات Excel المصدَّرة.
- جميع البيانات تبقى محفوظة محليًا في متصفح المستخدم فقط — لا يُرسَل أي شيء لأي خادم.
- **نسخ احتياطي كامل بصيغة JSON**: زر واحد لحفظ كل شيء (البيانات + الإعدادات + كل التعديلات اليدوية) في ملف، وزر آخر لاسترجاعه بالضبط كما كان — على هذا الجهاز أو أي جهاز آخر.
- **الوضع الليلي**: مفتاح تبديل في الشريط الجانبي للتنقل بين المظهر الفاتح والداكن، يُحفظ تلقائيًا.
- عرض كامل بلا تمرير داخلي عند اختيار فوج واحد بالاسم، للمراجعة والطباعة بشكل مريح.
- **قابل للتثبيت كتطبيق (PWA)**: زر "📲 تثبيت التطبيق على الجهاز" في الشريط الجانبي يثبّت DONIA SMART CLASSE كتطبيق مستقل (حاسوب أو هاتف)، يعمل بدون إنترنت بعد أول زيارة.

## 🚀 التثبيت والتشغيل

هذا تطبيق **ويب بملف واحد (`index.html`)** — لا يحتاج تثبيت برامج أو خادم. اختر إحدى الطريقتين:

### الطريقة 1 — رابط مباشر عبر GitHub Pages (مُستحسَنة)
1. من إعدادات هذا المستودع: **Settings → Pages**.
2. في **Branch** اختر `main` والمجلد `/ (root)`، ثم **Save**.
3. بعد دقيقة أو دقيقتين، سيكون التطبيق متاحًا على رابط من شكل:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
4. من Chrome أو Edge، سيظهر زر **"📲 تثبيت التطبيق على الجهاز"** في الشريط الجانبي — اضغطه لتثبيته كتطبيق مستقل (يحتاج `manifest.json` و `sw.js` في جذر المستودع كما هما).

### الطريقة 2 — تشغيل محلي بدون إنترنت تقريبًا
1. نزّل كل الملفات (زر **Code → Download ZIP**).
2. افتح `index.html` بالنقر المزدوج — يعمل في أي متصفح حديث (Chrome، Edge، Firefox).
3. يحتاج إنترنت فقط لتحميل الخطوط ومكتبة تصدير Excel عند أول تشغيل؛ التعديل والتنقل بين الصفحات يعمل بدون إنترنت بعد ذلك.
4. زر التثبيت لا يظهر عادةً عند الفتح المباشر للملف (`file://`) — يحتاج استضافة حقيقية كـ GitHub Pages.

> لا حاجة لـ Node.js أو Python أو أي خادم — هذا تطبيق HTML/JavaScript صرف يعمل بالكامل داخل المتصفح.

## 📂 محتوى المستودع

| الملف | الوصف |
|---|---|
| `index.html` | التطبيق كاملًا (الواجهة + المنطق + بيانات عرض تجريبية) — يتضمّن أيقونة المتصفح مدمجة بداخله |
| `manifest.json` | **مطلوب** لتفعيل ميزة "تثبيت التطبيق" — بدونه لن يظهر زر التثبيت |
| `sw.js` | **مطلوب** لنفس الميزة (Service Worker)، ويضيف أيضًا عمل التطبيق بدون إنترنت بعد أول زيارة |
| `icon.png` | أيقونة التطبيق (تُستخدم في رأس هذا الملف، وفي شاشة التثبيت) |
| `README.md` | هذا الملف |

> ⚠️ الملفان `manifest.json` و `sw.js` ضروريان لظهور زر/أيقونة "تثبيت" في المتصفح — احرص على رفعهما في **جذر المستودع** بجانب `index.html` تمامًا (وليس داخل مجلد فرعي)، وإلا فلن تُكتشف الميزة.

## 📘 طريقة الاستخدام السريعة

1. افتح صفحة **"معلومات المؤسسة"** وعرّف اسم متوسطتك والولاية.
2. من صفحة **"استيراد البيانات"**: ارفع ملفات الأقسام الحالية، ومحضر الوافدين الجدد، ونموذج معيدي/موجَّهي السنة الرابعة (نموذج جاهز للتنزيل من نفس الصفحة).
3. اضبط **"الخريطة المدرسية"** لكل مستوى — التحديث فوري بدون أي زر.
4. راجع كل مستوى وعدّل ما تشاء يدويًا.
5. صدّر القوائم النهائية من صفحة **"التصدير"**.

دليل استخدام كامل متوفر داخل التطبيق نفسه (صفحة "دليل الاستخدام").
